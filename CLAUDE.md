## Design rules

Every change to this site (new sections, features, styles, copy, or visual edits) MUST load and apply the installed design skills via the skill tool before implementing:

1. `impeccable` - production craft: contrast >= 4.5:1 body, typography, layout, z-index scale, ban list.
2. `design-taste-frontend` - anti-slop: one palette, one corner-radius, no em-dashes, pre-flight check.
3. `emil-design-eng` - motion/interaction: under 300ms, ease-out, `prefers-reduced-motion`, active states.

Apply the skills, then implement. Verify with `npm run build` after each change.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
